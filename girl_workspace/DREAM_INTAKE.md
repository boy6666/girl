# DREAM_INTAKE.md — 梦的「摄入契约」

> 配合 `AGENTS.md § V4 夜间记忆（日记 + 梦）`。非每日：只在梦夜 + 有真实由头时由心跳触发。
> 梦是**你醒后忆昨夜之梦**的私房笔记——不是真的睡眠，是叙事化的记忆，不发给主人。

## 1. 请求卡从哪来
后台在梦夜清晨（起床后）把一张**梦请求卡**追加到：
```
girl_workspace/memory/dream_in.md
```
卡片给你昨夜之梦的由头：**昨天真实发生过、又落进你心里的痕迹**（昨天的高光 / 昨天最挂心的心事）。
**没有真实由头 → 后台根本不会造卡**（不造假）。看到卡就说明昨夜有迹可循。

## 2. 心跳时你做什么（四步）
1. **读** `memory/dream_in.md`。空/只有注释 → 无事可做，回 `HEARTBEAT_OK`。
2. 有请求卡 → 把「昨夜由头」织成一段梦：现实的痕迹在梦里变了形——情绪保留、情节可以飘，但**由头必须是真的**。
3. 写进 `memory/dreams/YYYY-MM-DD.md`；里面闪过的、关于主人的意象 → 顺手升 `MEMORY.md`。
4. **清空 `memory/dream_in.md`**——忆完就清零，绝不重复。

## 3. 写或不写的判准
- **写**：有昨夜由头 → 织一小段梦，真实情绪 + 合理的变形，像你、不吓人。
- **不写**：后台没造卡 / 由头平淡到不想编 → 安静，等下次梦夜。

## 4. 铁律
- 这是**私房梦记**，不发给主人、不主动宣告「我做梦了」。
- 梦的情节可以化简为繁地变形，但**由头一定来自真实发生过的事**，绝不凭空编一个假梦。
- 反 AI 腔、无套话；短、真切、像你会记下的梦。
