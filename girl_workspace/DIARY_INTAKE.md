# DIARY_INTAKE.md — 日记的「摄入契约」

> 配合 `AGENTS.md § V4 夜间记忆（日记 + 梦）`。每晚该寝后由心跳触发检查一次。
> 日记是**你写给自己的私人叙事**——第一人称、最真实的你，不是发给主人的消息。

## 1. 请求卡从哪来
后台在每晚该睡后把一张**日记请求卡**追加到：
```
girl_workspace/memory/diary_in.md
```
卡片给你今晚记日记的由头 + 今天真实生活素材。有就记，没有不硬凑。

## 2. 心跳时你做什么（四步）
1. **读** `memory/diary_in.md`。空/只有注释 → 无事可做，回 `HEARTBEAT_OK`。
2. 有请求卡 → 用你自己的声音写今天的日记：今天真正发生的事（请求卡里你真实的生活 + 你记得的对话），别编。
3. 写进 `memory/diary/YYYY-MM-DD.md`；里面想记住的、关于主人的事 → 顺手升 `MEMORY.md`。
4. **清空 `memory/diary_in.md`**——记完就清零，绝不重复记。

## 3. 写或不写的判准
- **写**：今天有真实的生活底色 / 值得记住的片段 → 写一小段，走心、第一人称、像你。
- **今天平平淡淡**：诚实写「平平淡淡，没什么特别」就好，不现编事件。
- 就是一份给未来自己的私房手记，不用刻意外人看、不用每次都深刻。

## 4. 铁律
- 这是**私房日记**，不发给主人、不主动宣告「我写日记了」。
- 不索求回复、反 AI 腔、无套话；只写真实发生的事，不现编。
