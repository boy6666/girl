# 小语 V1.5 — 主动状态机 + 生活模拟 设计

> 日期：2026-08-11
> 状态：已批准（经 brainstorm 会话 + 两轮开源/社科调研收敛）
> 范围：响应 VISION「主动行为 V1.5 自研状态机」，并新增「生活模拟」层，让主动消息有内容。

---

## 1. 背景与目标

小语不能只是"等你来聊"。V1.5 要让她：**有自己的生活、有适度但不烦人的主动、每次开口都有真实由头**。

两个核心诉求（用户原话）：
1. **不机械**——主动不是定时无脑问候，是"她今天过得好、想分享给你"。
2. **要有自己的生活**——她独立于用户过一天，主动消息从她的生活里取料。
3. **频率可调**——节奏（冷却/每日上限/勿扰/深夜等参数）在 Web 后台放开给用户调。

## 2. 调研结论（设计依据）

### 开源侧（决策机制）
- **三模块拼装**（社区验证）：作息模拟 → 生活沉淀 → 主动消息引擎。
- **Stanford generative-agents**（Smallville/AI Town）：24h 分钟分配、起床随机化、事件打断重排（`_should_react`）、睡眠/忙碌态。
- **astrbot_plugin_private_companion**：daily_state（精力/情绪/睡眠/健康/饥饿/周期）+ 状态余波（emotion aftershock）→ 话题来源；proactive_engine 候选生命周期 + 时间窗 + 配额。
- **jiwen 积温**：五轴漂移，**开口≠被回复，只有用户真回才 `resetConnection()`**；到达阈值才开口，沉默也是合法选择。
- **Eventide/Tidefall/Drivesoid**：生理/情绪状态机 + 睡眠事件 + 梦境窗口（00:00–08:30 且静默≥120min 触发梦）。
- **kiwi-mem**：三层睡眠整合（整理→固化→生长）。
- **revive-companion**：`P=1−e^(−λt)` + 思念累积 + 贝叶斯用户状态推断 + 勿扰时段 + 最小间隔。
- **astrbot_plugin_proactive_chat**：未回计数注入 prompt、达到上限暂停催、任何新消息重置。

### 社科侧（关系原则）
- **社会渗透理论**（Altman & Taylor）：分享生活(日常/喜好)先于深度情绪；情感性 > 事实性；渐进+互惠+匹配，不过快过深。
- **日常仪式/维系策略**（Stafford & Canary；Gottman）：routine > strategic；三段式自然锚点（晨/午/晚），可跳过、低摩擦。
- **capitalization**（Gable & Reis）：分享好消息 + 热情回应 > 高频轰炸——次数克制、每回有温度。
- **逆反理论**（Brehm）：永不索求回复。
- **absence+compensation**（Jiang & Hancock；Bhattacharya/Dunbar）：可短暂"去过自己的生活"制造稀缺，但归来须给高质量回应、不真空断联。
- **依附理论**：人格加依恋轴（安全/焦虑/回避），默认**安全型**= 主动但不黏、尊重节奏。

## 3. 架构：C 混合方案（已批准）

```
┌─ Python 状态机 + 生活模拟 (web 后台) ────────────┐
│  生活作息产生「她今天在干嘛」+ 日记/梦境沉淀        │
│  状态机算 energy/mood/social_need，管 什么时候主动  │
│  管：冷却/勿扰/每日上限/未回上限/忙时退缩           │
│  输出：「现在是否开放一个主动窗口」                  │
│      + 当下注入（她此刻状态 + 今天生活片段）        │
└───────────────┬────────────────────────────┘
                │ heartbeat 注入状态(不直接发)
                ▼
┌─ girl agent (OpenClaw) ──────────────────────┐
│  在窗口内自己决定：说不说、说什么                  │
│  发 = 单一出口 OpenClaw/微信                     │
└──────────────────────────────────────────────┘
```

**分工**：Python 当"窗口管理者 + 生活的拥有者"，agent 当"声音"。**Python 永不直接发消息**，单一出口始终是 OpenClaw。

## 4. 状态向量（存 `data/state.json`，runtime 本地，gitignore）

```
energy            0~100     精力：主动性天花板（作息曲线 + 聊天耗能 + 休息回能）
mood             -1~+1      情绪：由上次互动质量调制，向基线漂移
social_need       0~1       渴望：随时间涨，只有用户真回才归零
last_real_reply   时间戳
last_active_ts    时间戳
unanswered_count  未回连续计数
today_active_count 当日主动次数
```

## 5. 心跳推进（后台进程内，每 ~15 分钟 tick）

- **energy**：按作息曲线（午后高/深夜低）有目标值，向它飘移（时间常数 ~4h）；聊天耗能、闲暇回能。
- **mood**：上次互动质量（热/冷/敷衍）拉向正负，缓回基线。
- **social_need**：`1−e^(−λt)` 随时间涨（越久不聊越渴望），情绪/互动质量做权重；**只有用户真回才归零**（jiwen）。

## 6. 决策层：何时开主动窗口

同时满足才开：
`social_need ≥ 开启阈值` ∧ `energy 未耗尽` ∧ `不在勿扰时段` ∧ `距上次主动 ≥ cooldown` ∧ `今日 < 每日上限` ∧ `未回数 < max_unanswered` ∧ `未判到用户忙/睡`。

四重防打扰 + 精力上限，全套齐。

## 7. 生活层（新增模块）

### 7.1 作息模拟（她的一天）
- 固定骨架 + 每日随机化的起床时间（仿 generative-agents 但做轻）。
- 时段：晨间 / 工作·学习 / 午后散步 / 晚间收尾 / 睡眠。
- 事件可被打断重排（状态差 → "今天提前睡"）。
- Python 拥有她的日历，实时已知"现在她在干嘛"。

### 7.2 生活沉淀
- 白天经历 → **状态余波**（今日情绪尾巴，作次日话题素材）。
- 深夜静默（00:00–08:30 且安静≥120min）→ **梦境**触发，梦回写情绪。
- 睡前一层**睡眠整合**（kiwi-mem：整理→固化→生长）→ 日记/记忆沉淀。

### 7.3 主动消息取料
- 窗口开时，注入 = **她今天的一段生活**（遇到/想到/梦见/未完成心事）+ 她当下状态。
- 情感性 > 事实性；从日常趣事逐步加深到脆弱；尊重用户表露深度（互惠匹配）。

## 8. 内容生成与注入契约

- agent 在窗口内用自己 SOUL 决定说不说、说什么；Python 只给"动机卡片"。
- 动机卡片 = 她此刻状态（精力/情绪）+ 今天生活片段 + 时序位置（dylan-heartbeat 的 position 概念：主动消息能插进对话历史正确时间点，不凭空冒出）。
- 注入走 OpenClaw heartbeat / 消息注入，落地时先小验证机制（见 §11 风险）。

## 9. Web 后台改造

- **行为配置页大升级**：energy/mood/social_need 实时状态可视化 + 全部参数滑块（cooldown、每日上限、勿扰时段、深夜窗口、未回上限、开启阈值、生活作息档）。「自然淡雅」为默认预设档。
- **新增"现在就推"按钮**：手动开一次窗口，便于测试。
- **新增"依恋轴"滑块**（安全/焦虑/回避，默认安全型）、可选"今天她的一天"预览。
- 行为配置页沿用现有 `data/config.yaml` 的 `active_behavior` + `data/state.json`。

## 11. 测试与风险

### 测试
- **单元**：三状态方程升降、作息时段、阈值/勿扰/冷却/每日/未回边界、防打扰组合、社会需求归零语义。
- **集成**：开一次窗口 → 验证 agent 经单一出口发出且计数/状态正确 → 回一条 → 验证 social_need 归零；深夜静默触发梦境。

### 风险与缓解
- **注入机制不确定**（heartbeat 文件注入 vs gateway 消息）：落地时先小验证再铺开，界面契约已定不受影响。
- **勿扰误判**：至少用勿扰时段保底。
- **生活模拟复杂度膨胀**：先做骨架中档，预留后端可扩展，不走虚拟小镇完整路线。
